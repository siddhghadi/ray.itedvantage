# Ray CRM

Private multi-business CRM for TechDecodes, ITedvantage, and Woolen Rangoli.

The first visit creates the private owner's password directly on the server.
The generated credential file under `storage/` is excluded from Git.

## Hosting

The application targets Hostinger Premium using PHP and MySQL. Deploy the
`main` branch to `public_html` for `ray.itedvantage.com`.
